How to build it in Wix

  1. Create the pages

    In Wix, add pages called Home, Services, Meet Leo, Success stories, For professionals and Urgent ATO notices. The menu wording is under “Header menu” below.

  2. Set the fonts

    Site Design → Text. Headings: Outfit Bold. Body: Inter Regular. Both are in Wix's font list. If not, upload the files from the fonts folder in the zip.

  3. Set the colours

    Site Design → Colors. Copy the hex codes from the section below into your theme.

  4. Paste the words

    Work page by page. Click Copy here, click a Wix text box, paste. Page headings go in Heading 1, section headings in Heading 2.

  5. Add images

    Upload the logo and Leo's photos from the images folder. For the diagrams, use the PNGs in illustrations.

  6. Want the animations?

    Add → Embed Code → Embed HTML. Open a file from the embeds folder in a text editor, copy everything, paste it into the Wix box.

  7. Link the buttons

    Click a Wix button → Link → Web address. Paste the link shown under that button below (JotForm or the booking page).

  8. Check on mobile

    Switch Wix to the mobile view and tidy any boxes that overlap before you publish.

Small Business Restructuring

Text

A formal process, run by a registered restructuring practitioner, through which an eligible company can propose a plan to its creditors, including the ATO. Depending on eligibility, practitioner advice and creditor approval, an SBR may help a company remain under the directors’ control, continue trading and propose a compromise of eligible debts. We coordinate the information and people involved, alongside your registered tax agent and lawyer.
